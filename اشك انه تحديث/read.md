# ⚡ Universal Pro Downloader

برنامج ويندوز (Python + CustomTkinter) لتحميل الملفات من **مستودعات GitHub اللي شكلها "فرع لكل رقم"** (زي قواعد الـ manifest/lua، كل فرع = App ID وجواه ملفاته) بأقصى سرعة ممكنة وبدقة كاملة: كل ملف بيتحفظ **زي ما هو متخزن في القاعدة بالظبط** (نفس البايتات)، من غير ZIP ومن غير فك أو ضغط.

---

## 🚀 المميزات

### التحميل
- **تحميل غير متزامن (asyncio + aiohttp)** بمئات الاتصالات في نفس الوقت، والبرنامج **بيظبط عدد الاتصالات لوحده** (بيزوّد لحد أعلى إنتاجية، ويقلل لو GitHub بدأ يرفض).
- **أي نوع ملفات**: lua, manifest, json, txt, zip, rar, exe… البرنامج بيقرأ كل الملفات المتخزنة في كل فرع، مش نوع واحد.
- **الملفات زي ما هي**: لو الملف متخزن كـ zip أو rar بيجيلك zip أو rar بالظبط، ولو عادي بيجيلك عادي. مفيش تعديل في المحتوى.
- **من غير ZIP**: قايمة الملفات بتتقرأ بنفس بروتوكول `git` (طلب واحد لكل 500 فرع)، وبعدها كل ملف بيتحمل لوحده.
- **التحقق من سلامة كل ملف**: بعد التحميل البرنامج بيحسب بصمة git (SHA-1) للملف ويقارنها بالبصمة المسجلة في القاعدة. لو مش متطابقة بيعيد التحميل.
- **كتابة آمنة**: الملف بيتكتب باسم `.part` وبعدين يتسمّى باسمه الحقيقي، فمفيش ملف ناقص يتحسب كمكتمل.

### الملفات الكبيرة (100 ميجا ← جيجابايتات)
- **بيتحمل على دفعات (Streaming) للقرص مباشرة**، من غير ما الملف يتحمل كله في الذاكرة.
- **من غير مهلة إجمالية**: الملف الكبير مبيتلغيش بعد دقيقتين. البرنامج بيستنى بس لو الاتصال وقف تماماً.
- **أي ملف 8 ميجا فأكتر يتعامل معاه كملف كبير** في قناة خاصة، **وأقصى 4 ملفات كبيرة في نفس الوقت** عشان ما يتقسمش الإنترنت على ملفات كتير فتتأخر كلها وتتلغي. الملفات الصغيرة بتكمل بمئات الاتصالات زي الأول.
- **تحميل متوازي للملف الكبير**: الملفات من 32 ميجا فأكتر بتتقسم لأجزاء (16 ميجا) وتتحمل بأكتر من اتصال في نفس الوقت.
- **استئناف من نفس النقطة**: لو وقفت البرنامج أو النت قطع، الملف الكبير بيكمل من اللي نزل منه (مش من الصفر).
- الملفات المؤقتة بتتحفظ في `Downloaded_Files/.partial/` وبتتمسح لوحدها بعد ما الملف يكتمل ويتأكد.
- لو الملف الكبير فيه بصمة مش مطابقة (مثلاً Git LFS) بيتحفظ برضه، وبيتكتب تنبيه في السجل.
- الأرقام (8 ميجا، 4 ملفات، 32 ميجا، 16 ميجا…) ثوابت في أول `app2.py` (`BIG_FILE`, `BIG_WORKERS`, `SEG_MIN`, `SEG_SIZE`, `SEG_CONN`) لو عاوز تغيّرها.

### عدم تحميل المكرر (توفير نت ووقت)
- البرنامج بيحتفظ **بفهرس لبصمة كل ملف** موجود في مجلد `Downloaded_Files` كله (`download_index.json`).
- لو الملف (بنفس المحتوى) **موجود في أي مجلد جوه `Downloaded_Files`**، حتى لو من مستودع تاني، **مبيتحملش تاني**. بيتعمل له رابط صلب (Hard link) في مجلد المستودع الحالي (من غير مساحة إضافية)، ولو مش ممكن بيتعمل نسخة محلية.
- أول مرة بيبني الفهرس ممكن ياخد وقت لو عندك ملفات كتير، وبعد كده بيحدّث نفسه بس.
- الملفات المتطابقة جوه نفس المستودع بتتحمل مرة واحدة وتتنسخ لباقي الأماكن.

### المستودعات
- **قايمة مستودعات**: زر **Repositories** بيفتح قايمة. تضيف رابط GitHub كامل أو `owner/repo`، وتمسح.
- **إضافة دفعة واحدة من ملف .txt**: زر **Import from .txt** بيفتح متصفح الملفات، تختار ملف نصي فيه رابط في كل سطر، وكل المستودعات بتتضاف مرة واحدة (المكرر والغلط بيتعدّى).
- **اختيار المستودع عند كل تحميل**: لما تدوس Start Download بيسألك تحمّل من أنهي مستودع (واحد أو أكتر).
- **واحد واحد**: لو اخترت أكتر من مستودع بيخلّص الأول بالكامل وبعدين التاني (عشان السرعة والدقة).
- **مجلد لكل مستودع**: `Downloaded_Files/<owner>__<repo>/<النوع>/<رقم>/الملف`.

### APP ID
- خانة **APP ID** (رقم أو حروف). البرنامج بيدوّر على الفرع بالاسم (من غير حساسية لحالة الحروف) وبيحمّل ملفاته بس.
- سيبها فاضية لتحميل كل المستودع.

### أنواع الملفات
- لو القاعدة فيها **أكتر من نوع ملفات** بتظهرلك نافذة بكل الأنواع وعدد ملفات كل نوع:
  - **من غير اختيار** وتدوس Start Download ← بينزّل **كل شيء**.
  - **اخترت أنواع** ← بينزّل الأنواع دي بس (من كل الفروع).
- التحميل مبيبدأش قبل ما النافذة تظهر وتأكد.

### التحكم
- **Pause / Resume** فوري (بيلغي الطلبات الجارية ويكمل بعدين).
- **Stop** بيوقف ويحفظ التقدم.
- **الاستئناف**: أي ملف موجود على القرص بيتخطى، فتقدر تقفل البرنامج وتكمل بعدين.
- **حد 1000 ملف في المجلد** (مجلد جديد تلقائياً: 1, 2, 3…) عشان Explorer يفضل سريع.

### الواجهة
- وضع داكن، ملء الشاشة، ومكبّرة وبتتمدد مع النافذة.
- **Files saved**: الملفات المحفوظة. **Files left**: المتبقي. **Speed**: ملف/ثانية و MB/s. **Elapsed**: الوقت الفعلي (من غير فترات الإيقاف المؤقت) ومعاه **ETA** تقديري.
- **ETA بيتحسب من حجم البيانات المتبقي** (متوسط حجم الملفات اللي نزلت + حجم الملفات الكبيرة المتبقي) وبسرعة آخر 40 ثانية. **وقت الإيقاف المؤقت مش بيتحسب** لا في Elapsed ولا في ETA، وبيظهر "paused" وقت الإيقاف.
- السجل (Activity) بيعرض كلمات الحالة بس (بدء، إيقاف مؤقت، توقف، انتهاء…)، **مفيش سطر لكل ملف**.

## 🛠️ التشغيل

### المتطلبات
- Python 3.9 أو أحدث (ويندوز).
- المكتبات:

```bash
pip install -r requirements.txt
```

### تشغيل البرنامج
```bash
python app2.py
```

### تحويله لـ EXE
شغّل `build_exe.bat` من نفس المجلد. هتلاقي البرنامج في `dist\UniversalProDownloader.exe`.
الإعدادات والتحميلات وسجل الأخطاء بتتعمل **جنب ملف الـ EXE**.

## 📖 طريقة الاستخدام خطوة بخطوة

1. **أضف مستودع**: اضغط **⚙ Repositories**، اكتب رابط المستودع (أو `owner/repo`) واضغط **Add**.
   - عندك مستودعات كتير؟ اكتبهم في ملف `.txt` (رابط في كل سطر) واضغط **Import from .txt**.
2. (اختياري) **GitHub token** في نفس النافذة. بيرفع حدود GitHub ويسمح بالمستودعات الخاصة.
3. (اختياري) اكتب **APP ID** لو عاوز ملفات App واحد بس.
4. اضغط **🚀 Start Download**.
5. اختار **المستودع (أو المستودعات)** اللي هتحمّل منها.
6. لو ظهرت نافذة **أنواع الملفات**: اختار اللي عاوزه، أو سيبها من غير اختيار لتحميل الكل، واضغط **Start Download**.
7. تابع التقدم. تقدر تعمل **Pause** و**Stop** في أي وقت.
8. **📂 Open Folder** بيفتح مجلد `Downloaded_Files`.

## 📁 شكل المجلدات

```
UniversalProDownloader/
├─ UniversalProDownloader.exe  (أو app2.py)
├─ download_state.json         الإعدادات (المستودعات، التوكن، آخر اختيار)
├─ download_index.json         فهرس بصمات الملفات (لمنع التحميل المكرر)
├─ error_log.txt              سجل الأخطاء (بيتعمل لو حصل خطأ)
└─ Downloaded_Files/
   ├─ .partial/               ملفات كبيرة نازلة جزئياً (بتكمل بعدين)
   ├─ owner1__repo1/
   │  ├─ lua/1/123.lua
   │  ├─ manifest/1/123_456.manifest
   │  └─ zip/1/123_data.zip
   └─ owner2__repo2/ ...
```

**أسماء الملفات:** الملف اللي اسمه رقم الفرع (`123.lua`) بيتحفظ باسمه. أي ملف تاني بيتحفظ باسم يبدأ برقم الفرع (`123_Key.vdf`) عشان الملفات من الفروع المختلفة ما تتخبطش. الملفات داخل مجلدات فرعية بتتحفظ باسم زي `123_sub__x.vdf`. **المحتوى نفسه مبيتغيرش.**

## ⚠️ ملاحظات مهمة

- **السرعة القصوى هي سرعة النت عندك.** لو متوسط الملف 200 كيلوبايت، فـ 1000 ملف في الثانية معناها حوالي 200 ميجابايت/ثانية، وده فوق أي خط منزلي. الملفات الصغيرة (lua, json) هي اللي بتوصل لمئات الملفات في الثانية.
- **التوكن بيتخزن كنص عادي** في `download_state.json`. متشاركش الملف ده مع حد.
- **الإيقاف يحفظ التقدم**: متخافش تقفل البرنامج في النص.
- **ملفات Git LFS**: لو مستودع بيخزن ملفاته الكبيرة بـ Git LFS، اللي بيتخزن في Git هو ملف نصي صغير (pointer). البرنامج بيحفظ اللي متخزن في القاعدة زي ما هو.
- **مجلد واحد بس لمنع التكرار**: الفهرس بيبص على `Downloaded_Files` بس. ملف موجود برا المجلد ده مش بيتحسب.

## 🧰 حل المشاكل

| المشكلة | الحل |
|---|---|
| رسالة "GitHub is throttling" | عادي. البرنامج بيقلل الاتصالات لوحده. التوكن بيقلل الحالة دي. |
| مستودع مش بيظهر ملفات | اتأكد إن الرابط صح وإن فروعه أرقام/أسماء فيها ملفات. المستودعات الخاصة محتاجة توكن. |
| ملف كبير وقف | اضغط Start Download تاني، هيكمل من اللي نزل. |
| خطأ غير متوقع | افتح `error_log.txt` وابعته. |
| الـ EXE مش بيشتغل | شغّل `app2.py` عادي وشوف الخطأ، وراجع `error_log.txt`. |

## 🔧 للمطورين (مختصر)

1. قراءة الفروع: `GET info/refs` ← كل فرع وcommit sha بتاعه.
2. قراءة الملفات: `POST git-upload-pack` (بروتوكول v2، `filter blob:none`) ← شجرة كل فرع بدون المحتوى، بتتفك بمحلل pack مكتوب بالبايثون (بيدعم ofs/ref delta).
3. التحميل: `raw.githubusercontent.com` لكل ملف، ملفات صغيرة بعدد اتصالات كبير ومتغير، وملفات كبيرة بقناة منفصلة (Streaming + Range + أجزاء متوازية).
4. السلامة: SHA-1 للملف = `sha1("blob <size>\0" + content)` ويتقارن بالـ sha من شجرة git.
